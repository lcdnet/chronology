# Chronology - Journaling Application

## Concept
This is an open source iOS app designed to help users quickly jot down their present thoughts and reflections. There are simple organizational filters by category, and the ability to track emotional trends with an Insights page. Each entry can also have photos attached to it.

## Platform & Tools
- **Framework** SwiftUI
- **DB/Persistence** SwiftData
- **IDE** XCode 15+ / iOS 26+

## Key Features
1. **Rich Entry Creation:** Input custom titles, reflection body text, mood indicators, category, and photos.
2. **Search Filter:** Entries can be searched for or filtered quickly by category.
3. **Data Management:** SwiftData persistence with swipe-to-delete and star-as-favorite qualities.
4. **Insights Dashboard:** Summarized statistics showing total reflections logged, starred entries, and a breakdown by mood.

## How To Set Up
1. Clone this repository
2. Open 'chronology.xcodeproj' in XCode.
3. Target iOS 17.0+ on iPhone simulator or your connected device.
4. Build & Run with 'CMD + R'
